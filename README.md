# Python Discount Calculator

A simple Python application that calculates the best available price using multiple discount strategies and Object-Oriented Programming (OOP).

## Features

- Apply percentage-based discounts.
- Apply fixed-amount discounts.
- Provide exclusive discounts for premium users.
- Check discount eligibility.
- Automatically select the lowest available price.

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## Python Concepts

- Abstraction (`ABC`, `@abstractmethod`)
- Inheritance and Polymorphism
- Method Overriding
- Type Hints
- Lists and Loops

## How to Run

Run the Python file:

```bash
python discount_calculator.py
```

## Example Output

```text
Best price for Wireless Mouse for Premium user: $40.00
```
